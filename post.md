I am thrilled to introduce my latest Computer Vision project: Real-Time Safety Helmet & Head Detection using YOLO11 & Streamlit! ⛑️✨

In industrial and construction environments, ensuring personal protective equipment (PPE) compliance is critical for worker safety. To help address this, I built an end-to-end AI detection system that accurately identifies whether workers are wearing safety helmets or have unprotected heads in real time.

🔍 Key Highlights & Technical Details:
- Model Architecture: Fine-tuned the latest YOLO11 model on a dataset of over 3,900 images (featuring 13,000+ bounding box annotations).
- Interactive Web App: Developed an intuitive UI using Streamlit, enabling users to upload images, adjust confidence thresholds on the fly, and view instant object summary counts.
- Tech Stack: Python, PyTorch, Ultralytics YOLO, OpenCV, Pandas, Streamlit.
